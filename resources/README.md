# Learning Resources

Place reference PDFs and study materials in this directory to make them available for download on the tools page.

## Current Resources

- `modern-professional-tattooing.pdf` — Main technical reference manual

## Adding New Resources

1. Place your PDF or reference file in this directory
2. Update `tools.html` with a corresponding resource card
3. Create an `<a>` link with `download` attribute pointing to the file path
