Setup Requirements

Browser: Chrome, Edge, or Opera (Web MIDI + WebRTC Audio)

DAW: Any DAW with MIDI output capability (Ableton, FL Studio, Logic, etc.)

Virtual MIDI: Set up a virtual MIDI loopback on your OS

Microphone: Built-in or external mic for audio streaming (optional)

Network: Stable internet to exchange SDP handshake with collaborator

Getting Started
  1. Connect your MIDI device or virtual port using "Connect MIDI" button
  2. Optionally enable "Audio Bridge" to stream live audio
  3. Click "Create Offer" to generate a session handshake
  4. Share your SDP using QR code or copy/paste
  5. Paste the remote collaborator's answer into the "Remote SDP" field
  6. Use "Patch Mode" to direct MIDI flow (DAW → Session or vice versa)
  7. Set tempo and monitor the activity log for connection status
Quick Reference

SDP: Session Description Protocol—the handshake text for WebRTC connection

Patch Mode: Controls whether MIDI flows from DAW to session or vice versa

Tempo: Syncs across the peer connection in real time

Audio Bridge: Streams live audio and receives remote mix through WebRTC
